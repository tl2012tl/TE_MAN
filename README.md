# TE MAN  v3.5

TE MAN 是首个专为 ComfyUI 打造的本地 + 在线 API 双线兼容无限画布插件，覆盖漫剧创作、提示词扩写、分镜生成、生图生视频、素材管理与AI助手等。插件为 ComfyUI 本地带来无限画布的创作体验，支持一键分镜、一键三视图、一键故事板、一键九宫格、自由裁切、多任务并发、资产素材库、提示词素材库、构想台 AI 、3D导演台、文本工具节点、节点自动连线、快速断线、自定义保存路径等功能，让本地模型和在线 API 都能更好用、更高效。

用了新特性，只支持 Python 3.12/3.13，可去 B 站下载我的 Py3.13 整合包https://pan.quark.cn/s/e1649b85eb60


## v3.5

### 1. TE MAN 3D导演台新增全景图与全景模式

**TE MAN 3D导演台** 现已支持加载本地全景图，可直接在 3D 场景中使用真实环境背景进行人物站位、镜头构图和场景预演。

- 支持上传 png、jpg、jpeg、webp 格式的本地全景图，并自动校验接近 `2:1` 的等距柱状全景比例。
- 全景图会自动保存到 ComfyUI `input` 目录，场景保存或重新打开工作流后可自动恢复。
- 顶部新增 **全景模式** 开关，位于骨骼模式左侧；开启后导演视角固定在全景中心，只进行原地上下左右环视。
- 全景模式可以避免导演视角前后移动、平移时产生错误的全景视差，让人物与真实环境之间的相对位置和透视关系更稳定，适合模拟人在现场原地环视的第一视角效果。
- 当需要检查人物在全景环境中的大小、地面落点、朝向和最终构图时，建议开启全景模式；当需要自由移动视角、拖动对象或从不同位置观察场景时，建议关闭全景模式。
- 普通导演视角仍保留原有环绕、平移和缩放操作，开关全景模式不会改变当前人物构图。
- 支持全景图水平旋转，可调整全景背景的正面朝向。
- 新增 **全景人物距离** 滑条，默认 `5m`，可在 `1.5-10m` 范围内调整人物与全景视点的距离。
- 全景图会显示在导演视角、机位视角和最终截图中，全景路径、模式状态、视点方向及距离参数会保存到 `scene_json`。

### 2. 3D导演台新增骨骼模式与 OpenPose 导入

**TE MAN 3D导演台** 新增骨骼模式，可在普通 3D 人偶参考之外，切换为黑底彩色 OpenPose 风格骨骼参考图；同时支持导入本地 OpenPose 骨骼图，自动识别骨骼点并生成可继续编辑的骨骼人偶。

- 顶部新增骨骼模式开关，开启后截图、发送至画布、加入资产库都会输出黑底彩色 OpenPose 骨骼图。
- 骨骼人偶可使用姿势预设和关节滑条继续微调动作。
- 支持 3D 人偶与骨骼人偶互相切换。
- 骨骼图输出采用标准 BODY_18 点结构，包含身体、四肢以及头部等关键点。
- 支持导入 png、jpg、jpeg、webp 等图片格式，自动识别 BODY_18 骨骼点并按平面位置生成骨骼人偶。
- 导入后的骨骼人偶可继续移动、旋转、缩放和调整关节。

### 3. 3D人偶支持整体等比缩放

点击单个人偶后，右侧设置栏新增 **整体等比缩放** 滑条，可在保持当前身高和体型比例的情况下整体放大或缩小人偶。

- 支持 `0.20x-3.00x` 等比例缩放，不会因三轴比例不同而把人偶拉长或压扁。
- 支持 3D 人偶、骨骼人偶和 OpenPose 平面人偶。
- 缩放倍率会随场景保存，并在 3D 人偶与骨骼人偶切换时继续继承。

### 4. 新增 TE MAN 批量提示词节点

新增 **TE MAN 批量提示词** 节点，可在一个节点内管理多条提示词，并按顺序或指定规则批量执行工作流，更适合批量生图、批量生视频、批量反推和多提示词测试。

- 使用卡片式提示词管理界面，支持新增、编辑、删除、上移、下移和单选。
- 支持 `txt分割导入`，可按回车 / 换行自动拆分成多条提示词。
- 支持 `导入txt文件夹`，可把文件夹下每个 txt 文件作为一条提示词导入。
- 支持 **批量执行**、**单选执行**
- 点停止执行会自动清理未开始的任务

### 5. 新增 TE MAN 批量图片节点

新增 **TE MAN 批量图片** 节点，可一次导入多张图片，并按图片顺序批量执行工作流，适合批量图生图、图生视频、批量反推和素材测试。

- 使用图片卡片 / 瀑布流式展示。
- 支持添加单张图片，也支持添加文件夹。
- 图片卡片支持单选、上移、下移和右上角 `×` 快速删除。


### 6. 新增批量增强设置节点

新增 **TE MAN 批量增强设置** 节点，用于控制批量执行方式，主批量节点界面更简洁，需要高级控制时再接入增强设置。

- 支持设置执行时间间隔，可控制每个任务之间等待多少秒。
- 支持从指定编号继续执行，例如从第 5 条提示词或第 5 张图片继续。
- 支持随机编号执行，可在当前范围内随机顺序入队。
- 支持执行范围设置，可选择只执行当前批量节点接入的工作流分支，减少同一工作流里其他无关流程被一起执行。

### 7. 加载保存图像节点增强

**TE MAN 加载图像&保存图像 Image** 节点新增保存文件名、多图查看和全景图查看能力，更适合配合批量节点使用，也可直接从全景环境中选择视角并裁切画面。

- 新增 `保存文件名` 文本输入口，可接入批量节点的文件名或自定义文本，用于动态控制保存文件名。
- 新增 `保存提示词` 输入口，接入文本后会在保存图片的同时保存同名 `.txt` 提示词文件。
- 新增 **多图输入** 按钮，默认关闭；开启后按钮变为橙色，可把多次输入或一次性输入的多张图瀑布流展示。
- 新增 **全景查看** 按钮，支持接近 `2:1` 比例的等距柱状全景图，并直接在节点原有图片预览区域内显示，无需打开新的预览窗口。
- 全景查看开启后按钮会显示独立的青绿色高亮；可使用鼠标左键拖动环视，使用滚轮调整视野远近，再次点击按钮即可恢复普通图片预览。
- 全景查看支持框选裁切。进入框选裁切后，左键用于绘制或移动裁切框，右键拖动用于继续调整全景方向，滚轮仍可调整视野。


### 8. GPT image 2节点更新

-快捷功能增加黑白速写故事板
-增加独立的提示词输入接口,方便接入提示词

## v3.3

### 1. 新增 TE MAN 3D导演台

新增 **TE MAN 3D导演台** 节点，可在 ComfyUI 内打开独立 3D 导演台悬浮面板，用 3D 空间直接摆放人物、道具和机位，生成更稳定的构图参考图。适合人物站位、分镜构图、镜头角度、多人关系和产品展示场景预演,建立后可直接发送至ComfyUI内使用。

- 支持添加标准人物、女性人物、不同体型素体和 GLB 角色。
- 支持添加方块、球体、圆柱等简单道具，对象可拖动、旋转、缩放和命名。
- 支持群演阵列，可统一控制多人站位和动作。
- 内置站立、行走、跑步、鞠躬、格斗、招手、坐下、跪地、躺下等姿势预设，并支持关节滑条微调。
- 内置正面、侧面、俯拍、仰拍、特写、中景、全景等常用机位，可![alt text](IMG_20251120_131241.png)在导演视角与机位视角之间切换。
- 右侧可实时预览机位画面，支持 16:9、9:16、1:1 等取景比例。
- 当前机位截图可发送至ComfyUI或加入资产库，方便直接接入后续生图、生视频流程。
- 场景会保存到节点的 `scene_json`，复制节点或刷新页面后可继续读取当前摆放状态。

## v3.0

本次更新围绕 **更强大的创作辅助、更漂亮的节点界面、更顺手的工作流操作** 进行升级。TE MAN 不再只是单个节点插件，也不再区分本地或在线 API 的使用场景，而是更完整的 ComfyUI 创作工作台。

### 1. 全新 TE MAN 构想台

新增顶部入口 **构想台**，可在 ComfyUI 内直接打开独立 AI 助手面板，用于提示词、分镜、剧本、项目策划和工作流思路整理。

- 支持独立 API 设置，可配置接口地址、API Key、模型名和请求格式。
- 支持 OpenAI Chat、Responses、Gemini、Claude 等多种接口格式。
- 支持多话题管理，不同项目、不同灵感可以分开保存上下文。
- 支持多个话题并行使用，同时使用多个话题。
- 支持话题重命名，方便用户按项目、客户、创意方向管理对话。
- 支持每个话题设置独立提示词，可把不同话题变成不同类型的专属助手。
- 新话题内置 4 个创作入口：剧本构造、提示词生成、分镜创想、项目拆解，高效辅助创作。

### 2. 加载保存图像节点 UI 全面升级

保存图像 / 加载图像节点不再是传统 ComfyUI 默认竖排控件样式，而是重新设计成更直观、更现代的 TE MAN 横排按钮 UI。

- 常用功能改为横排按钮展示，操作路径更短。
- 节点界面更紧凑、更美观，减少传统控件堆叠带来的杂乱感。
- TE MAN 节点操作更直观，减少反复拖线、找节点、断线的繁琐步骤。
- 输入口新增 `X` 快速断线按钮。
- 输出口支持双击自动连接最近的 TE MAN 节点输入口。

### 3. TE MAN 文本工具节点更新

新增 **TE MAN 文本工具** 功能，面向提示词扩写、分镜生成和视频提示词优化，让用户可以直接在 ComfyUI 工作流里完成文本创作，不需要频繁切换。

1. **9 段分镜提示词**：输入一个简单画面或剧情描述，自动生成 3x3 九宫格分镜提示词，并自动组合背后视角、过肩视角、主观视角、正面视角和高张力特殊视角。
2. **扩写生图提示词**：把一句简单描述扩写成更有电影感、细节更丰富的生图提示词。
3. **扩写生视频提示词**：把基础画面描述优化成适合视频生成模型的动态提示词。

### 4. 首创保存图像节点支持自定义保存路径

保存图像节点可以自由决定图片保存位置。填写绝对路径时，可直接保存到计算机内任意指定目录。

- 文件名自动使用 `TE_MAN_时间` 命名，减少手动设置成本。
- 留空时仍保存到 ComfyUI 默认 `output`。
- 填写自定义绝对路径时，可直接保存到指定目录，方便项目归档和素材管理。

### 5. 工具入口与稳定性优化

- TE MAN 的常用功能入口从节点内迁移到 ComfyUI 顶部，更像一个完整工具套件。
- 处理多处兼容和发布细节，让插件更稳定。
