# TE MAN  v3.3

TE MAN 是首个专为 ComfyUI 打造的本地 + 在线 API 双线兼容无限画布插件，覆盖漫剧创作、提示词扩写、分镜生成、生图生视频、素材管理与AI助手等。插件为 ComfyUI 本地带来无限画布的创作体验，支持一键分镜、一键三视图、一键故事板、一键九宫格、自由裁切、多任务并发、资产素材库、提示词素材库、构想台 AI 、3D导演台、文本工具节点、节点自动连线、快速断线、自定义保存路径等功能，让本地模型和在线 API 都能更好用、更高效。

用了新特性，只支持 Python 3.12/3.13，可去 B 站下载我的 Py3.13 整合包https://pan.quark.cn/s/e1649b85eb60


## v3.3

### 1. 新增 TE MAN 3D导演台

新增 **TE MAN 3D导演台** 节点，可在 ComfyUI 内打开独立 3D 导演台悬浮面板，用 3D 空间直接摆放人物、道具和机位，生成更稳定的构图参考图。适合人物站位、分镜构图、镜头角度、多人关系和产品展示场景预演,建立后可直接发送至ComfyUI内使用。

- 支持添加标准人物、女性人物、不同体型素体和 GLB 角色。
- 支持添加方块、球体、圆柱等简单道具，对象可拖动、旋转、缩放和命名。
- 支持群演阵列，可统一控制多人站位和动作。
- 内置站立、行走、跑步、鞠躬、格斗、招手、坐下、跪地、躺下等姿势预设，并支持关节滑条微调。
- 内置正面、侧面、俯拍、仰拍、特写、中景、全景等常用机位，可在导演视角与机位视角之间切换。
- 右侧可实时预览机位画面，支持 16:9、9:16、1:1 等取景比例。
- 当前机位截图可发送至ComfyUI或加入资产库，方便直接接入后续生图、生视频流程。
- 场景会保存到节点的 `scene_json`，复制节点或刷新页面后可继续读取当前摆放状态。


## v3.1

### 1. 新增 TE MAN TEXT文本展示节点

新增 **TE MAN TEXT文本展示** 节点，可在工作流里直接查看、编辑、复制、粘贴文本，并继续作为文本输出连接到其他节点。节点内置横排快捷按钮，适合整理提示词、分镜文案和 AI 生成结果。

### 2. 资产库支持保存提示词

资产素材库现在不仅能管理图片，也支持收藏 **提示词文本素材**。用户可一键把文本展示节点里的提示词加入素材库，按项目统一保存、预览、复制、重命名和再次添加到工作流，让常用提示词真正变成可复用资产。

### 3. 悬浮窗口支持拖动

资产库、构想台、预览窗口、添加素材窗口等悬浮面板现在可以拖动调整位置，边整理素材边创作更顺手。

### 4. 加载保存图像节点支持放大预览

**TE MAN 加载图像&保存图像 Image** 节点新增 **放大预览** 按钮，可直接在节点里打开大图预览窗口，支持缩放查看和拖动查看细节。


## v3.0

本次更新围绕 **更强大的创作辅助、更漂亮的节点界面、更顺手的工作流操作** 进行升级。TE MAN 不再只是单个节点插件，也不再区分本地或在线 API 的使用场景，而是更完整的 ComfyUI 创作工作台。

### 1. 全新 TE MAN 构想台

新增顶部入口 **构想台**，可在 ComfyUI 内直接打开独立 AI 助手面板，用于提示词、分镜、剧本、项目策划和工作流思路整理。

- 支持独立 API 设置，可配置接口地址、API Key、模型名和请求格式。
- 支持 OpenAI Chat、Responses、Gemini、Claude 等多种接口格式。
- 支持多话题管理，不同项目、不同灵感可以分开保存上下文。
- 支持多个话题并行使用，同时使用多个话题。
- 支持话题重命名，方便用户按项目、客户、创意方向管理对话。
- 支持每个话题设置独立提示词，可把不同话题变成不同类型的专属助手。
- 新话题内置 4 个创作入口：剧本构造、提示词生成、分镜创想、项目拆解，高效辅助创作。

### 2. 加载保存图像节点 UI 全面升级

保存图像 / 加载图像节点不再是传统 ComfyUI 默认竖排控件样式，而是重新设计成更直观、更现代的 TE MAN 横排按钮 UI。

- 常用功能改为横排按钮展示，操作路径更短。
- 节点界面更紧凑、更美观，减少传统控件堆叠带来的杂乱感。
- TE MAN 节点操作更直观，减少反复拖线、找节点、断线的繁琐步骤。
- 输入口新增 `X` 快速断线按钮。
- 输出口支持双击自动连接最近的 TE MAN 节点输入口。

### 3. TE MAN 文本工具节点更新

新增 **TE MAN 文本工具** 功能，面向提示词扩写、分镜生成和视频提示词优化，让用户可以直接在 ComfyUI 工作流里完成文本创作，不需要频繁切换。

1. **9 段分镜提示词**：输入一个简单画面或剧情描述，自动生成 3x3 九宫格分镜提示词，并自动组合背后视角、过肩视角、主观视角、正面视角和高张力特殊视角。
2. **扩写生图提示词**：把一句简单描述扩写成更有电影感、细节更丰富的生图提示词。
3. **扩写生视频提示词**：把基础画面描述优化成适合视频生成模型的动态提示词。

### 4. 首创保存图像节点支持自定义保存路径

保存图像节点可以自由决定图片保存位置。填写绝对路径时，可直接保存到计算机内任意指定目录。

- 文件名自动使用 `TE_MAN_时间` 命名，减少手动设置成本。
- 留空时仍保存到 ComfyUI 默认 `output`。
- 填写自定义绝对路径时，可直接保存到指定目录，方便项目归档和素材管理。

### 5. 工具入口与稳定性优化

- TE MAN 的常用功能入口从节点内迁移到 ComfyUI 顶部，更像一个完整工具套件。
- 处理多处兼容和发布细节，让插件更稳定。
